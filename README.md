# Task Organizer

A professional task management app with task sequels/evolution tracking, Google authentication, and real-time sync across all your devices.

## Features

- **Google Sign-in** — Access your tasks from any device
- **Task Evolution** — Complete tasks and reopen with sequel tasks, building a visible history chain
- **Emergency Rating** — Priority 1 (Low) to 5 (Critical), sorted automatically
- **Deadline Tracking** — Overdue tasks highlighted in red
- **Real-time Sync** — Changes appear instantly across all devices
- **Search** — Find tasks by title, description, or history
- **Responsive** — Works on desktop, tablet, and phone

## Tech Stack

- React 18 + Vite
- Firebase Auth (Google) + Firestore
- Firebase Hosting (free tier)
